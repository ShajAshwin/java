JWT AUTHENTICATION FLOW

JWT TOKEN STRUCTURE:

  +──────────────────────+   .   +──────────────────────+   .   +──────────────────────+
  │       HEADER         │       │       PAYLOAD        │       │      SIGNATURE       │
  │──────────────────────│       │──────────────────────│       │──────────────────────│
  │  Algorithm type      │       │  User data (JSON)    │       │  Hash of:            │
  │  e.g. HS256          │       │  userId, role, exp   │       │  Header + Payload    │
  │  Token type: JWT     │       │  + any custom claims │       │  + secret key        │
  +──────────────────────+       +──────────────────────+       +──────────────────────+

STEP 1:

             POST /login
  +--------+  ──────────────>  +──────────────────────+  ──────────────>  +─────────────────────+
  │        │                   │   Auth Controller    │                   │   Token Generator   │
  │ Client │                   │ Validates credentials│                   │  Signs + sets expiry│
  │        │                   +──────────────────────+                   +─────────────────────+
  +--------+                                                                     |
      ^                                                                          |
      │                    JWT token returned                                    |
      └──────────────────────────────────────────────────────────────────────────|
Token format:  Base64(Header) . Base64(Payload) . Signature

SUMMARY:
  1. Client sends credentials  -->  POST /login
  2. Auth Controller validates credentials
  3. Token Generator creates JWT  (Header . Payload . Signature)  with expiry
  4. JWT token returned to client
  5. Client attaches token to every request  -->  Authorization: Bearer <token>
  6. JWT Filter intercepts the request
       ├── Public route (e.g. /swagger-ui)  -->  Allow through directly
       └── Protected route                  -->  Validate token
             ├── Valid & not expired        -->  Forward to Controller  -->  200 OK
             └── Invalid / expired          -->  401 Unauthorized
