Key Takeaways
✅ List (Ordered, allows duplicates and null,has index): ArrayList, LinkedList, Vector
✅ Queue & Deque (FIFO, Double-ended): PriorityQueue, ArrayDeque
✅ Set (no order,  No duplicates, allows null, ): HashSet, LinkedHashSet(ordered), TreeSet
✅ Map (no order, Key-Value Pairs, No duplicate keys, allow null key and value): HashMap, LinkedHashMap(ordered), TreeMap
✅ Thread-Safe Collections: ConcurrentHashMap, CopyOnWriteArrayList, BlockingQueue

3) What is a arraylist?
ArrayList is a resizable array implementation of the List interface in Java.
Unlike arrays, it can grow and shrink dynamically as elements are added or removed.
It allows duplicate elements, maintains insertion order, and provides fast random access.

📌 How resizing works?
When adding an 11th element to an ArrayList with a capacity of 10:
*A new array (1.5x size) is created.
*Old elements are copied to the new array.
*The old array is discarded.

4)Difference Between ArrayList and LinkedList in Java
1️⃣ Implementation:
ArrayList uses a dynamic array internally.
LinkedList uses a doubly linked list internally.

ArrayList is faster for random access & iteration.
LinkedList is better for frequent insertions/deletions.
Java's LinkedList is rarely used unless modifications are frequent.

ArrayList	LinkedList
1) ArrayList internally uses a dynamic array to store the elements.	LinkedList internally uses a doubly linked list to store the elements.
2) Manipulation with ArrayList is slow because it internally uses an array. If any element is removed from the array, all the other elements are shifted in memory.	Manipulation with LinkedList is faster than ArrayList because it uses a doubly linked list, so no bit shifting is required in memory.
3) An ArrayList class can act as a list only because it implements List only.	LinkedList class can act as a list and queue both because it implements List and Deque interfaces.
4) ArrayList is better for storing and accessing data.	LinkedList is better for manipulating data.
5) The memory location for the elements of an ArrayList is contiguous.	The location for the elements of a linked list is not contagious.
6) Generally, when an ArrayList is initialized, a default capacity of 10 is assigned to the ArrayList.	There is no case of default capacity in a LinkedList. In LinkedList, an empty list is created when a LinkedList is initialized.
7) To be precise, an ArrayList is a resizable array.	LinkedList implements the doubly linked list of the list interface.
