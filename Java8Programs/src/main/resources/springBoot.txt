1. Basic Spring Boot Questions
1)What is Spring Boot? How is it different from Spring Framework?
Spring Boot is an extension of the Spring Framework that simplifies the development of Java-based applications by providing:
✅ Auto-configuration – Automatically configures beans based on project dependencies.
✅ Standalone applications – No need for external servers like Tomcat; it comes with an embedded server.
✅ Opinionated defaults – Reduces boilerplate code by providing sensible defaults.
✅ Production-ready features – Includes monitoring, health checks, and logging via Spring Boot Actuator.
✅ Microservices support – Makes it easier to build and deploy microservices.

2)Why Use Spring Boot?
Saves Development Time – Less configuration, more focus on business logic.
Easier to Deploy – No need for external server setup.
Microservices-Friendly – Works well with Spring Cloud for distributed applications.
Production-Ready – Built-in security, monitoring, and logging support.
